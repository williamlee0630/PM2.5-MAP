# 移除競賽品牌關聯設計

## 目標

從「空污共犯」網站及其可公開部署的資源中完整移除「智在家鄉」、聯發科技競賽與投稿關聯，避免搜尋引擎或生成式搜尋系統再次將平台描述成競賽作品。

## 修改範圍

- 首頁的 `<title>`、description、keywords、JSON-LD、FAQ 與可見正文。
- 其他頁面的 keywords，以及 `llms.txt`、README 和部署目錄內的 n8n 工作流程資料。
- 結構化資料中的競賽 `Event` 實體與任何競賽語意。
- 首頁結構化資料與 sitemap 的 `dateModified`／`lastmod` 更新為 `2026-07-23`。

## 保留項目

- 網站品牌維持「空污共犯 PM2.5 智慧監測平台」。
- 網址、canonical、WebSite、WebPage、Dataset、FAQ、Breadcrumb 等 GEO／SEO 架構維持不變。
- PM2.5 地圖、資料、圖表、導航、感測方法、研究限制與來源說明維持不變。
- 不調整版面、互動功能、資料來源或既有路由。

## 內容策略

首頁以平台的街道級 PM2.5 群眾觀測、資料分析及健康路線研究價值為主，不描述投稿或競賽歷史。原先競賽相關關鍵字改為具搜尋意圖且與產品一致的「台北空氣品質」、「移動空污感測」與「健康路線」。n8n 工作流程的顯示名稱與內嵌頁面標題改用「空污共犯」，避免公開靜態檔案成為殘留來源。

## 驗證

- README、`web/`、`server/` 與根目錄部署工具中不得再出現「智在家鄉」、「聯發科技」或競賽／投稿敘述；不會部署的任務規格與 Git 歷史不在此限制內。
- 所有 HTML 內的 JSON-LD 必須能解析為合法 JSON。
- sitemap 必須能解析為合法 XML。
- Git diff 僅包含上述文案、結構化資料、日期與必要的檔名調整。
