智慧健康防護導航 Beta 測試中

本功能串接 Python 後端演算法與 K-D Tree 空間索引技術。系統將會抓取導航 API 的多條替代路線，並與雲端樞紐的即時微型感測網進行交叉運算，為您規劃出曝露風險最低的「黃金健康路線」。

輸入起點、終點與交通方式後，系統比較替代路線附近最新可用的 PM2.5 感測值，提供相對較低曝露的路線參考。

仍在測試

地址解析、導航服務與後端皆可能暫時無法回應，請保留替代方案。

常見問題

健康路線是如何計算的？

系統比較導航服務提供的替代路線，並將路線附近最新可用的群眾 PM2.5 感測值納入相對曝露估算。

結果可以取代醫療或官方建議嗎？

不可以。此功能仍在測試，只提供路線比較參考；敏感族群應依醫療專業與官方空品資訊行動。

為什麼有時無法產生路線？

地址解析、導航服務、感測資料覆蓋或後端服務暫時不可用，都可能使計算失敗。
